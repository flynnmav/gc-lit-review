08 | Time-Optimal Collaborative Guidance Using the Generalized Hopf Formula

Kirchner M.R., Mar R., Hewer G., Darbon J., Osher S., Chow Y.T. | IEEE L-CSS 2018 | arXiv:1709.06590 (笔记页码 p.1–p.6 指 PDF 页码,与 arXiv v3 版面一致)

0. 一句话定位

把"多弹时间最优协同捕获机动目标"写成 k 弹联合状态下的 HJI 方程,用广义 Hopf 公式将值函数表示为与状态同维数 (4k) 的对偶变量 p 上的无网格、无约束极小化问题,从而绕开网格 HJI(水平集)方法的维数灾难;与 PN 族 [29][30] 相比考虑了机动目标和控制饱和、是微分博弈最优而非启发式,与 [31] 的多弹启发式相比是博弈论最优且不需单积分器"瞬时机动"假设;与一致性(consensus)类协同方法的对比原文未提及(p.1)。

1. 问题建模

  • 状态量(原文符号):单弹相对状态先取 x = [δx, δy, δθ]†(非线性模型 (1),p.2),线性化后重新声明为 x = [δx, δy, δvx, δvy]†,其中 δx, δy 为弹目位置偏移,δvx = Vp − Ve,δvy 为相对垂直速度(p.2);k 弹联合状态 χ ∈ R^{4×k} = (x1, …, xk)(p.2, Sec II-B)。
  • 控制量(原文符号):追击方横向加速度 ap、逃逸方横向加速度 ae(每弹一个标量输入);联合控制 âp = (ap1,…,apk)T 与公共的 âe(p.2, (4)–(5))。
  • 动力学模型(类型与方程):
    • 非线性相对运动学 (1)(p.2, Sec II-A):ẋ(t) = [Vp cos(δθ) − Ve + δy·ae/Ve; Vp sin(δθ) − δx·ae/Ve; ap/Vp − ae/Ve],基于两个"改进 Dubin's car"(加速度输入替代转向角速率)模型的相对状态 [27],且为逃逸者中心(evader-centric)构型。
    • 小角度线性化 (2)(p.2):ẋ = [0₂ I₂; 0₂ 0₂] x + [0;0;0;±1] ap + [0;0;0;−1] ae = Ax + B ap + D ae,± 号对应尾追(+)/迎头(−)。
    • 联合系统 (4)–(5)(p.2):块对角 A、B_i、公共 D,χ̇ = Âχ + B̂âp + D̂âe。
  • 目标泛函/终端条件(协同到达如何编码进代价):时间最优形式——运行代价取指示函数 L = I_C(落在控制集内代价 0,否则 +∞,p.3);终端代价取捕获椭球上的二次型 Jx(x) = ⟨x, W^{-1}x⟩ − 1,变换后 Jz(z) = ⟨z, V(0)z⟩ − 1(p.4);终端代价符号条件 (23):J<0 于 int Ω、J>0 于 Ω 外、J=0 于边界(p.4)。协同到达 = 任一弹捕获即成功:联合捕获集 Ω = ∪ᵢ Ωᵢ(6)(p.2–3),对应非凸终端代价 J(z,t) = min_{i=1,…,k} Ji(z,t) (24)(p.5);最小到达时间 T* 由 ϕ(z0,T)=0 的最小 T 给出,T* = argmin_{t<T} ϕ(z0,t)(p.5)。
  • 机动目标:逃逸者机动(输入 ae),且作为微分博弈的对抗方(adversarial)建模,目标是增大代价泛函 (19)(p.3–4);仿真闭环中逃逸者控制由值函数梯度求出(p.5, Sec V)。PN 类方法"目标运动但不机动"的假设被明确放弃(p.1)。
  • 约束(输入/状态/视场):输入约束 Ap = {ap : ‖Qp^{-1}(t) ap‖∞ ≤ 1},Ae = {ae : ‖Qe^{-1} ae‖∞ ≤ 1}(p.2),对角矩阵 Q 在正交方向独立缩放限幅,Qp(t) 时变(建模减速飞行器的气动舵面效率下降);双方控制对称(零中心)(p.2)。状态约束仅终端捕获集 Ω(椭球:‖[δx;δy]‖ ≤ r 且拦截速度 ≤ Vmax,p.2);视场约束:未提及。
  • 噪声/时延:未提及(模型为确定性;闭环仿真需获知逃逸者惯性状态,p.5)。

2. 假设条件

  1. 动力学(经 z(t) = e^{−tA}x(t) 变换后)必须是 f(u) 型无漂移系统,即原系统线性:ẋ = Ax + B(t)u(± 对抗项 D(t)w)(p.3, (14)(18));非线性系统留作未来工作(p.6, Sec VI)。
  2. 容许控制集 C ⊂ R^m 为凸集(p.3, (7) 下方)。
  3. 终端代价 J: R^n → R 为凸函数(p.3, (8) 下方);协同情形 J = minᵢ Ji 非凸,需借助 min-plus 代数,且要求哈密顿量凸(p.5, (24) 下方)。
  4. 运行代价 L: proper、下半连续、凸、1-coercive(p.3, (8) 下方)。
  5. 微分博弈的 Hopf 公式 (21) 成立要求 Isaacs 条件 H+ = H− = H±(此时 U = V);若 H+ ≠ H−,公式不成立(p.4, Sec III-C)。
  6. 联合哈密顿量 (22) 为凸的充分条件:Qe ≤ Qp 且系统限定为 (2)(4) 的形式(p.5);若 (22) 非凸,逐点最小只是真值函数的上界(引 [24])(p.5)。
  7. 终端代价满足符号条件 (23)(J 在 Ω 内负、外部正、边界零)(p.4)。
  8. 双方控制有界且对称(零中心)(p.2)。
  9. 单一逃逸者对 k 个追击者;除终端捕获集外无其他状态约束,未建模追击者间避碰/通信(由 (4) 的结构与全文内容可知,p.2)。
  10. 值函数梯度存在时,argmin p 即 ∇xϕ("provided the gradient exists",p.3);牛顿法中梯度/Hessian "忽略不连续点"(p.4–5)。
  11. 数值上:哈密顿量积分用固定步长 h 的矩形 Riemann 和预计算(p.4);矩阵指数用 2(Al-Mohy & Higham)在固定时间间隔上以有界误差近似(p.4)。

3. 方法核心

机制:把有界控制下的时间最优控制写成初值 HJ 方程——运行代价取控制集指示函数 I_C,把控制约束吸收进哈密顿量,使其成为控制集的支撑函数(对偶范数);广义 Hopf 公式断言该 HJ 方程的黏性解可以精确地写成对偶变量 p ∈ R^n(博弈情形 p ∈ R^{4k})上的无约束极小化,从而把"在 4k 维状态空间上网格化解 PDE"替换为"在 4k 维对偶空间解一个梯度/Hessian 可显式写出的非光滑极小化问题";极小元 p* 同时就是 ∇xϕ,最优控制由 H 对 p 的梯度关系恢复。协同(任一弹捕获即可)通过终端集取并集、终端代价取逐点最小 J = minᵢ Ji 编码;在哈密顿量凸的条件下用 max/min-plus 代数把该非凸初值问题拆成 k 个相互独立的凸 HJ 初值问题并行求解,再取逐点最小。

关键公式:

  • 捕获椭球 Ω = {x : ⟨x, W^{-1}x⟩ ≤ 1} (3),W = diag(r²,…,r²,V²max,V²max)(p.2)。
  • 联合捕获集 Ω = ∪ᵢ Ωᵢ (6)(p.3 顶部)。
  • 初值 HJ 方程 (10):∂ϕ/∂t + H(t, ∇xϕ) = 0,ϕ(x,0) = J(x),ϕ(x,t) = v(x, T−t)(p.3, Sec III-A)。
  • 哈密顿量 (11):H(p) = sup_{c∈R^m}{⟨−f(c), p⟩ − L(c)};取 L = I_C 后 H(p) = max_{c∈C}⟨−f(c), p⟩(p.3)。
  • Hopf 公式 (12):ϕ(x,t) = −min_{p∈R^n}{J⋆(p) + tH(p) − ⟨x,p⟩},为 (10) 的精确逐点黏性解(引 [11],[18])(p.3);Fenchel-Legendre 变换定义 (13);ϕ(x,t) = (J⋆ + tH)⋆(x),且 ∇xϕ(x,t) = argmin_{p∈R^n}{J⋆(p) + tH(p) − ⟨x,p⟩}(p.3)。
  • 状态变换 z(t) = e^{−tA}x(t) (15) → ż = e^{−tA}B(t)u (16)(p.3, Sec III-B)。
  • 时变 Hopf 公式 (17):ϕ(z,t) = −min_{p∈R^n}{J⋆_z(p,t) + ∫₀ᵗ H(p,s)ds − ⟨z,p⟩},H(p,t) = max_{c∈C}⟨e^{−(T−t)A}B(T−t)c, p⟩(引 [21, Sec 5.3.2, p.215])(p.3)。
  • 博弈上/下值函数与哈密顿量 H±、H+(p.4, Sec III-C);博弈 Hopf 公式 (21):ϕ(z,t) = −min_p{J⋆_z(p,t) + ∫₀ᵗ H±(p,s)ds − ⟨z,p⟩},H±(p,t) = max_{c∈C}⟨e^{−(T−t)Â}B(T−t)c, p⟩ − max_{d∈D}⟨e^{−(T−t)Â}D(T−t)d, p⟩(p.4)。
  • 联合系统哈密顿量 = 控制集对偶范数 (22):H(p,t) = ‖Qp(T−t) B̂† e^{−(T−t)Â†} p‖₁ − ‖Qe D̂† e^{−(T−t)Â†} p‖₁(p.4, Sec IV)。
  • 二次终端代价及其变换:Jz(z) = ⟨z, V(0)z⟩ − 1,V(t) = e^{(T−t)Â†}W^{-1}e^{(T−t)Â};J⋆_z(p,t) = 1 + ¼⟨p, V(0)^{-1}p⟩(范数的 Fenchel 变换为对偶范数,引 [6])(p.4)。
  • Hopf 极小化的梯度与 Hessian(p.5):∇pϕ(z,t) = V(0)^{-1}p/2 − z + h·Σ_{sk∈S}(Qp(sk)Ep(sk) sgn(Ep(sk)†p) − Qe(sk)Ee(sk) sgn(Ee(sk)†p)),其中 Ep(t) = e^{−(T−t)Â}B̂,Ee(t) = e^{−(T−t)Â}D̂;H_p(ϕ(z,t)) = V(0)^{-1}/2。
  • 最小时间:T* = argmin_{t<T} ϕ(z0,t);可达性判据:T* > 可用时间 T ⇒ Ω 不可达;最优控制关系:∇pH(∇zϕ(z0,T*), T*) = e^{−tÂ}B̂(t)a*_p + e^{−tÂ}D̂(t)a*_e(p.5)。
  • 协同分解 (24)(25):J(z,t) = min_{i=1,…,k} Ji(z,t);解 k 个独立初值问题 ∂φi/∂t + H(t, ∇zφi) = 0,φi(z,0) = Ji(z),取 ϕ(z,t) = min_{i=1,…,k} φi(z,t),各 φi 可并行(p.5)。
  • 数值实现:Riemann 和近似 ∫₀ᵗH;松弛牛顿法 [9],初值 p0 = V(0)z/2("无哈密顿量积分项的 Hopf 目标极小点"),步长初始 1(全牛顿)、函数值上升时减半,迭代变化范数小则终止(p.4–5)。

4. 理论结果

本文无编号的定理/命题/引理,理论结论均以引用或行文方式给出,逐条列出:

  1. 结论(引 [11],[18],[22]):Hopf 公式 (12) 是 HJ 方程 (10) 的精确(exact)、逐点(point-wise)黏性解。前提:(7) 型无漂移动力学、C 凸、J 凸、L proper/lsc/凸/1-coercive(p.3, Sec III-A)。
  2. 结论(引 [10]):(12) 的唯一极小元(若梯度存在)即 ∇xϕ,解值函数自动得梯度。前提:J⋆ + tH 的 Fenchel-Legendre 变换性质(p.3)。
  3. 结论(引 [21, Sec 5.3.2, p.215]):Hopf 公式可推广到时变哈密顿量,得 (17)。前提:线性系统经 (15) 变换(p.3, Sec III-B)。
  4. 结论(引 [14]):上/下值函数是可能非凸 HJI 方程的黏性解;若 H+ = H− = H± 则 U = V(博弈值存在)(p.4, Sec III-C)。
  5. 结论:若 H+ ≠ H−,则 Hopf 公式 (21) 不成立(p.4)。
  6. 结论(引 [11],[1],[16],[23],min-plus 代数):Hopf 公式可推广到"可写成凸集并集"的非凸初值(如 (6) 的联合终端集),前提是哈密顿量凸(p.5)。
  7. 结论(本文断言):当 Qe ≤ Qp 且系统限定为 (2)(4) 形式时,(22) 的哈密顿量是凸的(p.5)。
  8. 结论(引 [24]):(22) 非凸时,k 个凸问题解的逐点最小只是真值函数的上界(p.5)。
  9. 符号条件命题 ((23) 下方的直觉论证):ϕ(z0,T) < 0 ⟺ 存在控制在时间 T 内把 z0 驱入 Ω;使 ϕ(z0,T) = 0 的最小 T 即最小到达时间,对应控制即时间最优控制(p.4)。

5. 实验设置

  • 场景:平面(k=1 平面内)2-on-1 追逃,3 自由度(3DOF)闭环仿真;联合状态维数 4k = 8;MATLAB R2016a + Simulink,120 Hz,Euler 积分;每弹配三阶自动驾驶仪;逃逸者控制由值函数梯度求出(p.5, Sec V)。
  • 参数:捕获半径 r = 3 m;|ae| ≤ 10 m/s²;|apk| ≤ (t−40)²/40 m/s²(0 ≤ t ≤ 40,否则 0,时变递减);Ve = 50 m/s,Vp = 255.225 m/s(0.75 Mach)。例 1 尾追,初始距离 4000 m,双弹同时正对目标发射;例 2 迎头,初始距离 6000 m,其余参数同例 1(p.5–6)。
  • 对比方法:未做网格 HJI 的受控对比实验。维数灾难的论证靠引用:[19] 在 4 维网格(30 点/维、低精度)上算 4 分钟,45 点/维、高精度时跳到 1 小时(p.1);本文报告自身求解时间为平均 40–83 ms(3 GHz Intel Core i7 950)(p.5)。
  • 评价指标:脱靶量(miss distance)、拦截时间、单次最优控制求解时间;例 1:脱靶 0.879 m < r = 3 m,拦截 19.533 s,期间 Qe ≤ Qp 保持、哈密顿量全程凸(p.5);例 2:中途线性化误差大导致 Ω 一度判不可达而回退 PN,凸性假设 Qe ≤ Qp 仅在最后 0.158 s(约 0.78% 交战时间)被违反,脱靶 2.34 m,拦截 20.158 s(p.6)。双弹在例 1 中自发分开对目标形成包围(p.5)。

6. 局限性

  • 作者承认的:
    • 线性化误差大时,零水平集时间可能超过可用飞行时间 T,Ω 被判不可达,仿真回退到比例导引 PN;只能靠增大逃逸者控制界来缓解(p.5–6)。
    • 凸性假设 Qe ≤ Qp 在例 2 最后 0.158 s(约 0.78%)被违反(p.6)。
    • 若 H+ ≠ H−(Isaacs 条件不成立),Hopf 公式 (21) 不成立(p.4)。
    • (22) 非凸时,逐点最小只是真值函数上界而非精确值(p.5)。
    • T* > 可用时间 T 时 Ω 不可达(方法只保证"可达集内启动必拦截",p.1, p.5)。
    • 方法目前限于线性系统;推广到反馈线性化类非线性系统、以及梯度/Hessian 未知时的分裂算法 [11][17][8] 留作未来工作(p.6)。
  • 我分析的(推断依据):
    • 动力学过度简化:(2) 中输入仅出现在 δvy 通道(±ap / −ae),无重力、阻力、姿态/速度耦合;有效性只在 3DOF 点质量 + 三阶自动驾驶仪的数值仿真中验证(p.2, p.5),工程弹体适用性存疑。
    • 缺乏同题基线对比:与网格 HJI 的比较仅是引用数字([19] 的 4 min/1 h,p.1)而非在同一 8 维问题上实测;40–83 ms 的"实时性"也未与 PN 等轻量方法对比计算量。
    • 可扩展性未验证:Hopf 极小化维数 = 联合状态维数 4k,且牛顿每次迭代需对 |S| 个预采样时刻求和并计算两组矩阵指数项;实验只做了 k=2,k 增大时的计算增长无数据。
    • "协同"语义较弱:协同仅体现为终端集取并集(任一弹捕获即成功,(6)),无弹间避碰、任务分配或通信拓扑建模(全文未出现此类约束)。
    • T* 求解成本被轻描淡写:T* = argmin_{t<T} ϕ(z0,t) 意味着对每个候选时刻都要解一次 4k 维非光滑极小化;闭环 120 Hz 下完整流程(含 T* 扫描)的开销结构未细化。
  • (拿不准的推断移入第 8 节。)

7. 可复现性

  • 已给出:模型方程 (1)(2)(4) 完整;捕获集 W 的结构(r 与 Vmax 的作用,p.2);控制集形式与对称性;两个算例的全部标称参数(r、|ae| 上界、|apk|(t) 公式、Ve、Vp、初始距离、尾追/迎头几何);求解器细节(松弛牛顿 [9]、初值 p0 = V(0)z/2、步长减半规则、终止条件定性描述);Riemann 矩形求积 + 固定步长 h 预采样;矩阵指数算法引文 [2];实验平台(3 GHz i7-950、MATLAB R2016a/Simulink、120 Hz Euler、三阶自动驾驶仪);结果指标(脱靶量、拦截时间、平均求解时间)。
  • 缺失:Vmax 数值;Qp(t)、Qe 的具体取值及其与算例中标量界 |ae|、|apk| 的对应关系;三阶自动驾驶仪参数;牛顿收敛阈值数值;求积步长 h 与样本数 |S|;T* 搜索的具体算法(扫描/二分?);算例中逃逸者的具体输入/轨迹;"Qe ≤ Qp"的确切含义(逐元素?);由 ∇pH 关系式分离出 a*_p 与 a*_e 的具体步骤;无代码或数据发布(全文未给出仓库/链接)。

8. 待验证

以下推测无法在原文定位到明确出处:

  1. 初值 p0 = V(0)z/2 与"无哈密顿量积分项的 Hopf 目标极小点"自称矛盾:按 J⋆_z(p) = 1 + ¼⟨p, V(0)^{-1}p⟩ 求极小应得 p = 2V(0)z,而文中写 V(0)z/2——疑为排版或记号(V(0) 定义位置差异)问题,需复算确认(p.4–5)。
  2. "40–83 ms"是 8 维联合问题(k=2)含 T* 搜索的单次完整求解平均时间,还是单个 φi 问题或单次牛顿迭代的耗时,原文未明说(p.5)。
  3. χ ∈ R^{4×k} 应理解为 R^{4k}(k 弹各 4 状态堆叠);按字面的 4×k 矩阵记法与 (4) 的堆叠式不完全一致(p.2)。
  4. 最优控制关系式 ∇pH(∇zϕ(z0,T*), T*) = e^{−tÂ}B̂(t)a*_p + e^{−tÂ}D̂(t)a*_e 中时间写作 t 而非 T*,疑为笔误;且如何从该"和式"中同时解出 a*_p 与 a*_e(可能通过 H± 中两个 max 的 argmax 结构)原文未给出(p.5)。
  5. 尾追(+)/迎头(−)的 B 矩阵符号在交战中是否切换、切换判据与引起的抖动未讨论(p.2)。
