04 | Multiple Pursuer Multiple Evader Differential Games

Garcia E., Casbeer D.W., Von Moll A., Pachter M. | arXiv 长文 | arXiv:1911.03806 (v1, 2019-11-09, 29页)

0. 一句话定位

在边界防御微分博弈(BDDG)谱系中,本文把单追单逃的 Apollonius 圆解"拼接"进 N 追 vs. M 逃的团队博弈,同时求解离散的武器-目标分配(target selection)与连续的状态反馈制导:与文献 31(Stackelberg 开环 + HJB 局部近似)和 32(半开环 + pairwise outcomes 近似)不同(p.3),本文声称给出 Isaacs 意义下的完整闭式解——Value 函数连续、C¹ 且满足 HJI PDE,克服维数灾难(p.3, p.21 Remark 5);解决的是"追方数量占优(N≥M)且承诺初始分配"下的静态一次分配问题,N>M 时追方用两追共捕一逃利用数量优势,再分配(renegotiation)只作为鲁棒性推论和开放问题处理。

1. 问题建模

  • 状态量(原文符号):完整博弈状态 x := (x_{P1}, y_{P1}, ..., x_{PN}, y_{PN}, x_{E1}, y_{E1}, ..., x_{EM}, y_{EM}) ∈ R^{2(N+M)}(p.4);2v2 情形写作 x := (x_{E1}, y_{E1}, x_{E2}, y_{E2}, x_{P1}, y_{P1}, x_{P2}, y_{P2}) ∈ R^8(p.7);含离散分配变量的增广状态 x̄ = [x^T μ^T]^T(p.5)。
  • 控制量(原文符号):追方团队 u_P = {ψ_i}, i=1,...,N;逃方团队 u_E = {φ_j}, j=1,...,M,均为瞬时航向角,可许集 ψ_i, φ_j ∈ [−π, π)(p.4-5)。
  • 动力学模型(类型与方程):简单运动(simple motion,常速质点),式 (1)(p.5):ẋ_{Pi} = v_{Pi} cos ψ_i, ẏ_{Pi} = v_{Pi} sin ψ_i,ẋ_{Ej} = v_{Ej} cos φ_j, ẏ_{Ej} = v_{Ej} sin φ_j,带初始条件 x_{Pi0}, y_{Pi0}, x_{Ej0}, y_{Ej0};共 2(N+M) 个微分方程。
  • 参与者数量与团队结构:N 个追捕者/防御者 P_i(i=1,...,N)与 M 个逃逸者/攻击者 E_j(j=1,...,M),N ≥ M(p.4);队内合作、队间非合作(p.2)。
  • 支付/终端流形:Mayer 型终端成本 J(u_P, u_E; x_0) = Φ(x_f),Φ(x_f) := Σ_{j=1}^M y_{Ej}(t_f)(式 (3)-(4), p.5-6);终端集 T := {x̄ | ∀j, ∃i, μ_ij = 1, x_{Pi}=x_{Ej}, y_{Pi}=y_{Ej}}(式 (2), p.5,点捕获);每对 (i,j) 有两种终止方式:y_{Ej}=0(逃逸者抵达边界)或被捕获(p.5);t_f 为最后一个逃逸者被捕获的时刻,个体拦截时刻 t_{fij} 之后该对状态冻结(ẋ=ẏ=0)(p.5);Value V(x_0) := max_{u_P} min_{u_E} J(式 (5), p.6)。
  • 机动目标:逃逸者是完全理性博弈参与者(非被动目标),简单运动;论文证明最优策略要求双方以最大速度运动,故记 v_{Pi} = v*_{Pi} = v̄_{Pi}、v_{Ej} = v*_{Ej} = v̄_{Ej}(p.4)。
  • 约束(输入/状态/视场):输入仅有航向角 ∈ [−π,π),速度取常值上界;分配约束:每个追捕者至多分配一个逃逸者 Σ_{j=1}^M μ_ij ≤ 1(p.5),终端集允许一个逃逸者被多个追捕者共同捕获(N>M 情形,p.5);博弈在半平面 y ≥ 0 进行,边界为 x 轴(p.5);点捕获;视场约束:未提及(隐含全状态可观测,p.12 Remark 2 "all agents are aware of the state of the system")。
  • 噪声/时延:未提及。

2. 假设条件

  1. N ≥ M(追方数量不劣于逃方)(p.4, Sec. II)。
  2. 追方速度优势:对所有 i,j 有 α_ij = v_{Ej}/v_{Pi} < 1(p.4);作者注明可推广到"部分追捕者慢于部分逃逸者"的情形——只需在分配上加约束(慢追捕者不分配给快逃逸者),但未展开分析(p.4)。
  3. 速度异质(不假设同速):v_{Pi}、v_{Ej} 各不相同,成对定义速度比;追捕者之间也可不同速,定义追-追速度比 α_{i'i} = v_{Pi}/v_{Pi'} < 1(P_{i'} 为较快者)(p.15)。
  4. 最优性下全员最大速度、航向恒定(p.4, Theorem 1 p.7)。
  5. 简单运动动力学,无转弯半径/过载/自动驾驶仪动态(p.4-5, 式 (1))。
  6. 二维平面假设:边界为 x 轴直线,博弈域为半平面 y ≥ 0(p.5)。
  7. 点捕获(point capture)(p.5)。
  8. 一个追捕者至多捕一个逃逸者:Σ_j μ_ij ≤ 1;但一个逃逸者可被至多两个追捕者同时捕获("up to two (but not more)", p.27)(p.5, p.27)。
  9. 坚定承诺(firm commitment):μ_ij(t) = μ_ij(t_0),追方锁定初始分配、交战中不换目标(p.6);第 VI 节放宽该假设仅得鲁棒性结果(Corollary 1, p.24)。
  10. 关注 Game of Degree,且只在追方必胜域 R_P ⊂ R^{2(N+M)} 内求解(域内保证全部逃逸者被捕获);策略同时给出 Game of Kind 的解(Remark 4, p.5, p.21)。
  11. 被捕获个体状态冻结(ẋ_{Pi} = ẏ_{Pi} = ẋ_{Ej} = ẏ_{Ej}, t ≥ t_{fij})以保证解的正则性、让博弈持续到最后一个逃逸者被捕获(p.5)。
  12. 角色固定:P 队永远追、E 队永远逃(BDDG 场景设定,p.2),全文未提及角色转换。
  13. 全状态信息:每个参与者都知道系统完整状态,可各自独立算出完整解(p.12 Remark 2)。

3. 方法核心

机制一句话:对每个追-逃对 (P_i, E_j) 作 Apollonius 圆(圆内为 E_j 的支配区、圆外为 P_i 的支配区,p.7),单对最优拦截点取圆的最低点 y_ij = y_{cij} − r_{ij}(p.9);把 N=M 的所有可行分配 A_ι 枚举,每个分配的团队支付是若干个"圆最低点"之和,取 max 得 Value;N>M 时用两个 Apollonius 圆相交的透镜区收缩逃逸者支配区、构造两追共捕项;最后逐项验证 V 连续、C¹、满足 HJI。关键公式:

  • 对 (P_i,E_j) 的 Apollonius 圆最低点(= 该对的支付项),式 (8)(p.7): y_ij(x) = (y_{Ej} − α²_ij y_{Pi} − α_ij d_ij)/(1 − α²_ij),其中 d_ij = √((x_{Ej}−x_{Pi})² + (y_{Ej}−y_{Pi})²)(式 (13), p.8)。
  • Apollonius 圆心与半径(式 (22), p.14):x_{cij} = (x_{Ej} − α²_ij x_{Pi})/(1 − α²_ij),y_{cij} = (y_{Ej} − α²_ij y_{Pi})/(1 − α²_ij),r_ij = α_ij d_ij/(1 − α²_ij)。
  • 2v2 两种分配的支付 y_{s1} = y_{11}+y_{22},y_{s2} = y_{12}+y_{21}(式 (9), p.7);最优分配 ι* = arg max_{ι=1,2} y_{sι}(p.9)。
  • 一般分配支付,式 (18)(N=M, p.12)与式 (24)(N>M, p.16):y_{sι}(x) = Σ_{j=1}^M μ^ι_ij y_ij(x);可行分配 = 所有配对的 Apollonius 圆不与 x 轴相交(图 2 示例,p.12-13)。
  • 最优状态反馈航向 = 指向最优瞄准点的单位向量(式 (10) p.8,式 (19) p.13);瞄准点闭式(式 (11)-(12) p.8,式 (20) p.13):x*_{Ej} = x*_{Pi} = (x_{Ej} − α²_ij x_{Pi})/(1 − α²_ij),y*_{Ej} = y*_{Pi} = (y_{Ej} − α²_ij y_{Pi} − α_ij d_ij)/(1 − α²_ij)(对 μ*_ij = 1 的配对)。
  • N>M 协同追捕:两追共捕时逃逸者支配区收缩为两圆交集(透镜形),最低点在两圆交点 I(图 3.a, p.13-14);追-追 Apollonius 圆(式 (23), p.15)用于确定两追捕者同时到达的点;两 E-P 圆相减得根轴线性方程 2(x_{ci'j}−x_{cij})x + 2(y_{ci'j}−y_{cij})y = R_ij(式 (28), p.17),代入 (23) 得 y 的二次方程(式 (29), p.17),其适用解即同时捕获支付项: V_s(x) = (F_ij − √((x_{cij}−x_{ci'j})² G_ij))/D_ij(式 (25), p.16),系数 F_ij, G_ij, D_ij, R_ij 见式 (26)(p.17);同时捕获瞄准点 x* = [R_ij − 2(y_{ci'j}−y_{cij})V_s]/(2(x_{ci'j}−x_{cij})),y* = V_s(式 (27), p.17)。
  • HJI 验证:−∂V/∂t = ∂V/∂x·f + g 中 ∂V/∂t = 0、g = 0(p.10),代入最优航向后逐项抵消,∫V/∂x·f = 0(2v2:式 (16)-(17), p.10-11;N>M 的 V_s 项:式 (34)-(39), p.19-21)。
  • 分配问题的 LP 形式:max J = ΣΣ y_{i,j} μ_{i,j} s.t. Σ_i μ_{i,j} = 1(每个逃逸者恰一个追捕者)、Σ_j μ_{i,j} = 1(每个追捕者恰一个逃逸者)(式 (43)-(45), p.26-27),可用匈牙利算法求解 [37];N>M 时允许每逃逸者至多两追,需计算的距离数为 M!N!/[(N−M)!]²(2M−N)(p.27)。

4. 理论结果

  • Theorem 1(p.7):最优 play 下所有参与者航向恒定、最优轨迹为直线。前提:简单运动 + Mayer 型成本。
  • Theorem 2(p.7-11):2v2 BDDG(α_ij < 1,x ∈ R_P,承诺初始分配):V(x) = y_{s1}(若 y_{s1} > y_{s2})或 y_{s2}(若 y_{s2} > y_{s1});V 连续、连续可微(dispersal surface y_{s1} = y_{s2} 上除外)、满足 HJI;最优状态反馈航向 (10)、瞄准点 (11)-(12)。证明中给出梯度 (14)(p.10)并证明 dispersal surface 上两种分配等优、V 连续但不可微(p.11)。
  • Remark 1(p.11):虽承诺分配,航向 (10) 是状态反馈律,可在线利用逃方任何非最优机动,且终端支付只会增大(对追方有利)。
  • Remark 2(p.12):每个 agent 无需通信即可独立计算完整解(分配+全员航向);仅在 dispersal surface 上需一次通信去冲突(deconfliction),否则两追可能同捕一逃、放跑另一逃。
  • Theorem 3(p.12-13):N=M 的 N vs. M BDDG(α_ij < 1,x ∈ R_P):V(x) = max_ι y_{sι}(x),最优分配 ι* = arg max_ι A_ι;V 连续、C¹(dispersal surface y_{sι} = y_{sι'} 除外)、满足 HJI;航向 (19)、瞄准点 (20)。证明沿用 Theorem 2,略。
  • Remark 3(p.14):两个 E-P Apollonius 圆相交是同时捕获的必要而非充分条件;逃逸者恒在两圆内部,故两圆从不互斥;圆相交但单圆弧最低点更低时仍单追捕获(图 3.b 数值例:交点 y=7.846 > 单圆最低点 y=7.642,p.14-15)。
  • Theorem 4(p.17-21):N>M 的 BDDG(α_ij < 1,x ∈ R_P):V(x) = max_ι y_{sι}(x),其中单追捕获项为 (8)、两追同时捕获项为 V_s(x) (25);V 连续、C¹(dispersal surface 除外)、满足 HJI;瞄准点为 (20)(单捕)或 (27)+(y* = V_s)(共捕);最优航向仍为 (19)。证明中论证 D ≠ 0、G ≠ 0 在相关区域恒成立(p.19)。
  • Remark 4(p.21):N<M 时按问题设定逃方必胜(M−N 个逃逸者可达边界);Game of Kind:若最优分配中每个 y_ij > 0 则边界完全可保(V > 0),否则只能部分保护、最优分配最小化突防逃逸者数量。
  • Remark 5(p.21):闭式解随参与者数量扩展性好;可行分配枚举只在交战开始时做一次(承诺假设下)。
  • Corollary 1(p.24):2v2 无承诺(不锁定初始分配)博弈中,承诺情形的追方策略 (40)-(42) 构成无承诺博弈的鲁棒状态反馈策略,保底支付 y_s = max(y_{s1}, y_{s2})。前提:α_ij < 1,x ∈ R_P。
  • Remark 6(p.24-25):何时换分配有利与 dispersal surface 相关,是开放问题;并明确 y_s 只是追方可达支付的下界,不是无承诺博弈的值。
  • Remark 7(p.25):放宽承诺后可用"协同 + 换班"(cooperation and switch)扩展 R_P:两追先共捕收缩逃逸者支配区,随后其一脱离转攻其他目标。
  • Appendix A 结果(p.25-26,非正式命题):3P1E 边界防御中,第三个追捕者不提升支付(图 6.b 中三圆共点时去掉任一冗余追捕者拦截点不变),故无需考虑三追共捕;拦截点唯一 ⇒ 无奇异面,saddle point 状态反馈策略存在;对比 [36] 的 capture-time 成本则可出现三追同时捕获。

定理/命题计数:4 个定理 + 1 个推论 + 7 个注释(Remark)+ 附录 2 项非正式结果。

6. 局限性

  • 作者承认的:
    • 承诺假设:追方锁定初始分配不换目标(p.6);无承诺 2v2 只得到保底下界 y_s,真正的 Value 未求出(Remark 6, p.25;附录 B p.27 "the Value of the game has not been found");何时换分配有利是开放问题(p.24-25)。
    • N < M 未解决:按设定逃方必胜,只定性建议追方"尽量多拦 + 拦最远的 N 个"(Remark 4, p.21)。
    • 每个逃逸者最多两追共捕,"up to two (but not more)"(p.27);三追共捕无增益仅在 3P1E 附加例中论证(p.26)。
    • 部分追捕者慢于部分逃逸者的情形只提出"用分配约束规避",未分析(p.4)。
    • 扩展方向(诱饵 decoys、牺牲型自损、目标重要性分级)留待未来研究(p.23, Sec. VI)。
    • dispersal surface 上 V 不可微,需要一次通信事件去冲突(Remark 2, p.12;Theorem 2 证明, p.11)。
  • 我分析的(推断依据):
    • 简单运动假设忽略转弯半径、过载限制与自动驾驶仪滞后(依据:式 (1) 仅为常速质点,p.5),直接映射到飞行器/导弹需松弛模型;论文的导弹拦截动机(p.6)与该假设有落差。
    • 二维 + 直线静态边界(p.5),未涉及三维空间、弯曲或多段边界、多个防御资产。
    • 支付 Σ y_{Ej}(t_f) 线性可加、无权重(依据:式 (4), p.6),无法表达不同逃逸者威胁等级差异——作者也承认重要性分级是未来工作(p.23)。
    • 可行分配枚举复杂度为阶乘级 M!N!/[(N−M)!]²(2M−N)(p.27),作者以"仅算一次"辩护扩展性(p.21),但对大规模 N、M 仍构成瓶颈,且全文无运行时间数据支撑"real time 实现可行"(p.3)的论断。
    • 完美信息、无噪声/时延/传感视场约束(全文未提及),与实际拦截场景的 BDA/量测噪声不符。
    • 被捕获个体冻结(p.5)与承诺绑定,意味着已捕获的追捕者不可再分配,进一步限制 N>M 剩余兵力的动态利用(Remark 7 的 cooperation-and-switch 仅在无承诺下定性讨论, p.25)。
    • 鲁棒性结论只由单点算例(例 1.2-1.4)展示,无系统性量化(依据:第 V 节仅 4 个轨迹图, p.21-23)。
