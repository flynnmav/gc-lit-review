12 | Cooperative Guidance of Multiple Missiles: a Hybrid Co-evolutionary Approach

Lan X., Chen J., Zhao Z., Zou T. | arXiv:2208.07156 (v2, 2022) | 页眉标注 IEEE Transactions on Control Systems Technology(录用格式稿,卷期页码文中未给出);作者单位:广州大学机电工程学院(p.1)

0. 一句话定位

离线优化类协同制导的代表:把多弹"同时到达 + 指定碰撞角"的协同制导描述为分布式多目标协同优化问题(摘要,p.1),每一枚导弹对应一个种群,用改进的自然进化策略 NCES(对邻居样本概率做"置信度重缩放"的自然梯度)在仿真中训练各弹的神经网络一致性控制器,再与比例导引 PNG 跟踪项混合成 HCCGL 执行(p.3-4, p.7)。注意:标题中的"hybrid"指解析 PNG 与学习式 NN 控制器的混合制导律(p.1 摘要、p.3-II.E),并非"遗传/差分进化 + 另一优化器"的混合优化器;与解析法/一致性法的根本区别在于不推导闭式协同控制律,而是在策略参数空间用无值函数的 ES 直接对适应度(一致误差的奖励积分)做协同进化搜索(p.1-2, p.4)。训练闭环发生在并行仿真器内(Algorithm 1 + Fig.5,p.7),属"仿真中优化 + 训练后执行"路线。

1. 问题建模

  • 状态量(原文符号):每弹全状态由三类特征构成(Table I,p.3):个人特征 P_mi=(x_i, y_i)、α_mi、Ξ_mi、V_mi;目标特征 P_T=(x_T, y_T)、V_T、α_T;误差特征 e_t^i、e_a^i、e_Ξ^i。几何量 r_i(相对距离)、t_go^i(剩余时间,Eq.(2))(p.2)。观测按 POMDP 处理:O_i × A_i → O'_i(Eq.(3),p.3)。
  • 控制量/决策变量:
    • 导弹物理控制量:a_li(侧向加速度,垂直于 V_mi)与 a_vi(推力加速度,沿 V_mi 方向)(p.2,Fig.1)。制导输出 u_i = (1−η)u_pi + η u_ei 为二维向量 侧向, 纵向(Eq.(11)(14),p.3-4)。
    • 优化器决策变量:神经网络权值矩阵 W_1i ∈ R^{3×q1}、W_2i ∈ R^{q1×q2}、W_3i ∈ R^{q2×2},合记 θ_i = W_3i, W_2i, W_1i(Eq.(12),p.4;p.7)。即进化搜索的是 NN 参数,不是直接的加速度序列。
  • 动力学模型(类型与方程):二维质点运动学模型(速度可控,含推力),Eq.(1)(p.2): ṙ_i = −V_mi cos δ_mi + V_T cos δ_Ti;r_i Ξ̇_mi = −V_mi sin δ_mi + V_T sin δ_Ti;α̇_mi = a_li/V_mi;α̇_T = a_T/V_T;V̇_mi = a_vi;δ_mi = α_mi − Ξ_mi;δ_Ti = α_T − Ξ_mi(按原文印刷,δ_Ti 定义疑有笔误)。 时间 t_go^i = −r_i/ṙ_i(Eq.(2),p.2)。
  • 协同结构(如何把"协同"编码进优化问题):通信拓扑为无向图,节点集 V={v1,...,vn},邻接矩阵 A=[a_ij],邻居集 N_i(II-B,p.3,Fig.2)。协同通过三重机制编码:(1) 每弹适应度中的共识误差项 e_t^i = Σ_{j∈N_i}(t_go^i − t_go^j)(Eq.(4))、e_a^i = Σ_{j∈N_i}(e_Ξ^i − e_Ξ^j)(Eq.(5)),其中 e_Ξ^i = Ξ_mi − Ξ_di,期望碰撞角 Ξ_di = Ξ_d1 + Σ_{j=1}^{i−1} δ_j^d(Eq.(6))(p.3);(2) 种群 i 的适应度依赖邻居参数集 ς_i = {θ_i, θ_j : j∈N_i},即 Fi(ς_i)(Eq.(20),p.5);(3) 所有种群每代同时更新(co-evolution,III-B,p.4),梯度按置信度重缩放以抑制邻居交互偏差(Eq.(23)(24),p.5)。学习率各弹共享(p.6)。
  • 目标泛函/终端条件:终端奖励 r_T^i = (γa·e^{−ξa|e_Ξ^i|} + γt·e^{−ξt|e_t^i|})·ϵ(k),ϵ(k) 为终端步指示函数(Eq.(7)(8),p.3);飞行奖励 r_F^i = βa(−1+e^{−ka|e_a^i|}) + βt(−1+e^{−kt|e_t^i|}) ≤ 0(Eq.(9),p.3);适应度 F_i = ∫_t (r_F^i + r_T^i)dt,最大化(Eq.(10),p.3)。终端条件:拦截命中(结果以 ZEM 报告,p.11-12)+ 撞击时间一致(e_t)与期望撞击角(e_Ξ)。联合适应度 F_tot 见 Eq.(15)(p.4)。
  • 机动目标:建模层面含 α̇_T = a_T/V_T(p.2);仿真 Case 2 中目标以 a_T = 5g sin(π t/7) 机动,V_T = 130 m/s,α_T = 162°(p.11)。
  • 约束(输入/状态/视场):Table III(p.9):最大侧向过载 a_lmax = 50g,最大推力过载 av_max = 5g,速度上/下界 V_max = 900 m/s、V_min = 350 m/s。NN 输出经有界激活约束:ψ(·)=Tanh 且 ||ψ(·)|| ≤ a_lmax(p.4)。视场约束:未提及。
  • 噪声/时延:未提及。仅假设目标特征"估计误差相对所需制导精度可忽略"、只需相对误差信息(II-C,p.3);训练评估中未提及注入过程/观测噪声或通信时延。

2. 假设条件

  1. 二维平面拦截几何,惯性系 OXY 为水平面(II-A,p.2,Fig.1)。
  2. 目标特征经弹上设备估计/探测,估计误差可忽略;精确绝对定位需 GPS 支持,本文只需相对误差信息(II-C,p.3)。
  3. 通信拓扑为无向图,邻居间可共享信息(II-B,p.3)。
  4. 问题为部分可观测 MDP(POMDP,Eq.(3),p.3);III-A 的 MDP 讨论中假设"确定性环境转移概率为 1"(p.4)。
  5. 协同进化中 θ'_i 与 θ'_j 独立采样,故 p(ς'_i|ς_i) = p(θ'_i)·Π_{j∈N_i} p(θ'_j)(III-C,p.5)。
  6. NCES 核心假设:个体适应度 F_i(θ'_i) 虽不可分步获得,但其期望存在,且对邻居参数分布不变("the expectation of the individual fitness does [exist], and is invariant to the parameter distributions of its neighboring agents",p.5)。
  7. 采用与 [20] 同精神的 rank-based 适应度整形,整形后仍记 F_i(·);采样扰动用 mirrored sampling(p.6)。
  8. "Considering peer pressure, each missile is assigned the same learning rate"——各弹共用同一学习率(p.6)。
  9. 定理 1 证明中的假设:(a) 单隐层神经网络可任意精度逼近多元连续函数(引 [37],p.7);(b) 变换后的适应度 F_i(E_ui^k) 对策略控制完全可微,且 ∂F_i(|E_ui^k|)/∂|E_ui^k| < 0(Eq.(40),p.8);(c) |E_ui^k| 位于 |E_ui^{l−1}| 的微小邻域内,Taylor 一阶展开"相当精确"(p.8);(d) |E_ui^k| 采样自以 |E_ui^{l−1}| 为中心的无偏正态分布,故 B_i^k → 0(m→∞)(Eq.(46),p.8)。
  10. frameskip 的适当调整"will facilitate the training process without affecting the final results"(经验性设定,case1/2 取 12,case3 取 40)(p.8)。
  11. 优化问题为确定性仿真评估:除 ES 自身的采样扰动外,未提及随机扰动、量测噪声、时延进入适应度评估(全文未见相关内容)。
  12. 协同是"仿真中离线训练 + 在线执行":训练以主从式/全分布式并行仿真完成(Algorithm 1、Fig.5,III-IV 节,p.7);论文未出现"offline training"的明示表述,亦未讨论部署后是否继续更新(该保留意见见第 8 节)。
  13. 目标可以运动(Case 2, p.11),但问题建模与适应度设计均未对目标机动模型做显式可预知性假设说明。

3. 方法核心

机制:HCCGL 由 PNG 跟踪项与 NN 一致性项凸组合而成——u_pi = [β Ξ̇_mi V_mi, 0]^T(仅设计侧向加速度,Eq.(11),p.3),u_ei = W_3i^T ψ(Z_2i),Z_2i = W_2i^T φ(Z_1i),Z_1i = W_1i^T φ(X_i),输入 X_i = [e_a^i, e_t^i, e_Ξ^i]^T(两隐层 + 输出层,φ=Sigmoid,ψ=Tanh,Eq.(12)(13),p.4),u_i = (1−η)u_pi + η u_ei(Eq.(14),p.4)。NN 权值 θ_i 由 NCES 训练:每个导弹一个种群,适应度 Fi(ς_i) 依赖邻居;由于有限采样下联合分布期望的估计偏差随分布维数线性增长(p.5),NCES 只对当前种群 θ_i 的期望建模(Eq.(22)),用邻居样本概率 Π_{c∈N_i} p(θ'_c) 作为"置信度"乘到原适应度上做重缩放(Eq.(23)(24)),使估计偏差保持在单种群水平(p.5-6,Fig.3-4 用 eggholder 变体 Eq.(26) 做了可视化论证);配合 elitist 学习率自适应(Eq.(27)-(29):在 η_α 邻域线性取 l+1 个候选,按 Σ_i G_i 最大者更新,全弹共享)、标称期望碰撞角 Ξ_d1 的自动搜索(Eq.(30)(31):从 U(−π,π) 采 h 个候选,按 H(Ξ_d1^k)=F_tot(θ_init) 择优,p.6)、rank-based 适应度整形与 mirrored sampling(p.6)。训练在主从式并行仿真中按 Algorithm 1 迭代(采样 m 组个体 → 并行评估 → 计算重缩放自然梯度 → 梯度上升;每 ρ 代做一次学习率适配)(p.7,Fig.5);终止条件为"until stopping criterion is met",具体准则未给出(Algorithm 1,p.7)。收敛性由定理 1 给出(见第 4 节)。

关键公式(标出处):

  • Eq.(11):u_pi = [β Ξ̇_mi V_mi, 0]^T,PNG 跟踪项,β 为导航比(p.3)。
  • Eq.(12)(13):NN 一致性控制器结构与输入 X_i(p.4)。
  • Eq.(14):u_i = (1−η)u_pi + η u_ei,η 为权衡增益(p.4)。
  • Eq.(20)(21):邻域联合适应度期望与其梯度 ∇θi E{Fi(ς'_i)} = E(ς'_i){∇θi log p(θ'_i)·Fi(ς'_i)}(p.5)。
  • Eq.(23)(24):置信度重缩放后的个体期望与梯度 ∇θi E_θ'i Fi(θ'_i) = E_θ'i(∇θi log p(θ'_i)·Fi(ς'_i)·Π_{c∈N_i} p(θ'_c))(p.5)。
  • Eq.(25):φ(θ'_i) = ∫ φ(ς'_i) p(θ'_c) dθ'_c,个体期望与联合期望的关系(p.5)。
  • Eq.(26):eggholder 变体演示函数(p.6,Table II)。
  • Eq.(27)(28)(29):候选学习率 η_cad = clip((1+0.1k)η_α, η_α^min, η_α^max),k∈Z,−l/2≤k≤l/2;评估函数 G_i;η'_α = argmax_{η_cad^k}(Σ_{i=1}^n G_i)(p.6)。
  • Eq.(30)(31):Ξ*_d1 = argmax H(Ξ_d1^k),H(Ξ_d1^k) = F_tot(θ_init)|_{Ξ_d1=Ξ_d1^k}(p.6)。
  • Eq.(32):g_θi = (1/(mσ²)) Σ_{k=1}^m Fi(ς'_i) ϵ_i Π_{c∈N_i} p(ϵ_c),单变量零均值高斯 N(0,σ²) 采样扰动(p.7;正文求和指标印为 Σ_{i=1}^m,疑笔误;Algorithm 1 中的写法为 Σ_{k=1}^m Fi(ς_i^k)ϵ_i^k Π_{c∈N_i} p(ϵ_c^k),p.7)。
  • Eq.(33)-(50):定理 1 的证明链条(p.7-8)。

4. 理论结果

  • Theorem 1(p.7,证明 p.7-8):在控制策略 Eq.(14) 与 Algorithm 1 更新策略下,通过选取合适的学习率、采样方差与种群规模,当迭代数 l→∞ 时,所得控制策略收敛到最优控制策略的一个小邻域。前提/证明要点:NN 可由等效单隐层表示(Eq.(35),引 [37]);策略误差 E_ui^[l] = u_i^[l] − u*_i 满足 E_ui^[l] − E_ui^[l−1] = ηη_α g_θi^l−1(Eq.(38));对变换适应度做 Taylor 一阶展开得对角负定 Jacobian G_i^l−1(Eq.(41)(42));B_i^k→0(m→∞)(Eq.(46));A_i^k>0、P_i^k>0(Eq.(47)(48));于是 Δ|E_ui^[l]| < 0(Eq.(49)),最终 lim_{l→∞}|E_ui^[l]| = δ_e,δ_e→0 as m→∞(Eq.(50))。
  • 性质如实记录:全文仅此 1 个定理;另有 Remark 1(p.5)为 NCES 的定义性说明(非定理)。证明给出的是"收敛到小邻域"的定性结论,无收敛速率、无全局最优性保证;且依赖第 2 节第 9 条的多条强假设(可微性、单调性、Taylor 有效性、m→∞)。III-C 关于重缩放梯度能把偏差"保持在单种群水平"的论断(p.6)仅由 eggholder 数值演示(Fig.3-4)与经验结果支撑,未形式化为引理;作者同时说明当种群规模很大(如数千)时该方法可能不再带来额外精度提升(p.6)。

5. 实验设置

  • 场景与弹数:三个场景。Case 1:4 弹协同攻击静止目标,目标位于 (9500, 9000) m,期望相对碰撞角 δ_d^i = 20°, 60°, 30°(i=1,2,3;M4 的 δ_d 未给出),初值见 Table V(M1(1900,17000)m,−25°,700 m/s;M2(1500,13000)m,0°,650 m/s;M3(1400,4000)m,5°,700 m/s;M4(3000,1300)m,10°,680 m/s)(p.9)。Case 2:4 弹,机动目标 a_T = 5g sin(πt/7),V_T = 130 m/s,α_T = 162°,其余初值同 Case 1(p.11)。Case 3:Monte-Carlo,5 弹位置随机采样(x_i ~ U(2000,2600),y_i ~ U(11000,13000)−2000i),初始弹道倾角 0°,速度均为 600 m/s,δ_d 均为 25°,静止目标 (10000, 9000) m,共 200 episodes(p.12)。
  • 对比基线:Case 1 与 TASCGL(Lyu et al. [38],时空协同制导律)对比,分有向拓扑版 TASCGLa 与按本文无向拓扑重实现的 TASCGLb;作者承认对比采用了与原方法略有差异的统一初值(因该法"对初值敏感脆弱")(p.9)。Case 2、3 无外部基线,仅报告自身结果(p.11-12)。
  • 评价指标:共识时间误差 e_t^i(s)、共识角误差 e_a^i(°)、零控脱靶量 ZEM(m)(Table VI-VIII,p.11-12);训练侧指标为平均适应度曲线(Fig.13)与学习率曲线(Fig.14)(p.13-14)。
  • 运行统计:Case 3 为 200 episodes 的 Monte-Carlo,报告各弹 Mean/Max/Min(Table VIII,p.12):e_a 均值 0.22°~0.93°(均 <1°),e_t 均值 0.45~0.61 s(多数 <1 s),ZEM 均值 3.74E-4~5.89E-3 m;未报告方差/标准差。Case 1、2 为单场景运行,未说明独立重复次数。关键数字:Case 1 中 HCCGL 的 |e_t| ≤ 0.05 s,而 TASCGLa/b 最大达 5.54 s / 4.82 s;TASCGL 因设计未考虑速度边界导致撞击时间失同步(p.11,Table VI)。Case 2:e_a 全部 <1°,|e_t| ≤ 0.455 s,ZEM ≤ 0.928 m(Table VII,p.11)。
  • 参数:约束 Table III(50g / 5g / 900 / 350 m/s)与超参 Table IV(p.9):τ=5 ms,η=0.3,η_α=0.015,σ=0.2,l=20,m=140,ρ=50,β=4,k_a=1,k_t=0.2,ξ_a=10,ξ_t=1,λ_a=4000,λ_t=2000,β_a=10,β_t=2;frameskip=12(case1/2)、40(case3)(p.8)。

6. 局限性

  • 作者承认的:
    1. 重缩放梯度仅在种群规模有限、邻居较多时有优势;种群规模很大(如数千)时可能不再带来额外精度提升(p.6)。
    2. 随机初值(Case 3)下学习率"不易稳定",若无学习率自适应,适应度曲线末期会抖动而非收敛("regardless of the types of optimizer")(p.13)。
    3. 对比实验采用了与原方法"略有不同"的统一初值,理由是 TASCGL 对初值敏感脆弱(p.9)——即对比公平性有折扣。
    4. 未处理执行机构故障与系统不确定性,增量制导增益留作未来工作(p.13,结论)。
  • 我分析的(附推断依据):
    1. 定理 1 是启发式论证:假设变换适应度对策略完全可微且 ∂F_i/∂|E|<0(Eq.(40)(42),p.8)、Taylor 一阶有效(p.8)、需 m→∞ 才能保证 B_i^k→0(Eq.(46)),结论仅为收敛到小邻域(Eq.(50)),无速率与最优性;且 F_i(E_ui^k): R^p→R^p 的维度表述(p.8)本身可疑(适应度应为标量)。
    2. 计算成本未报告:无训练时长、收敛迭代数、总评估次数;学习率适配每次需额外评估候选(p.6 Eq.(27)-(28)),真实评估开销被低估,而制导类在线应用恰对此敏感。
    3. 鲁棒性链条薄弱:假设目标估计误差可忽略(p.3),无噪声/时延/模型失配实验;Case 2 只测了单一正弦机动(p.11),且未说明仿真中目标机动规律对训练器是否已知。
    4. 泛化性存疑:NN 输入只有 e_a, e_t, e_Ξ(Eq.(13),p.4),不含 r_i、V_mi 等;三个 case 各自有训练收敛曲线(Fig.13,p.13),未验证单一策略跨场景/跨弹数迁移。
    5. 速度/推力约束的执行机制不明:p.4 只约束了侧向输出(||ψ||≤a_lmax),而 V∈[350,900]、a_v≤5g(Table III,p.9)如何在学习/执行中强制保证未给出;对比法正因速度边界处理不当而失同步(p.11),本文对应机制缺叙述。
    6. 协同维度仅时间+碰撞角一致,无避碰、视场、多目标/交战顺序等约束(全文未涉及)。
    7. Case 1 中 4 弹只给了 3 个 δ_d^i(p.9),M4 期望角缺失,复现对比存在缺口。
